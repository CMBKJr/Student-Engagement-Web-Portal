## How to Run Student Engagement Web Portal App on Localhost

### Follow these steps to start both the frontend and backend locally.

#### 1. Open Two Terminals in the Project Root Folder

You will use one terminal for the frontend and the other for the backend.

### Frontend Setup

#### 2. In the first terminal

```
cd frontend
```

#### 3. Install all frontend dependencies

```
   npm install
```

#### 4. Start the React development server

```
   npm run dev
```

This will start your frontend on
http://localhost:5173

##### Enter the link into your web browser of choice

### Backend Setup

#### 5. In the second terminal

```
cd backend
```

#### 6. Install all backend dependencies

```
   npm install
```

#### 7. Start the server

```
   npm run dev
```

Your backend will start on
http://localhost:8080
